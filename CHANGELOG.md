# История изменений

Версии по схеме [SemVer](https://semver.org/lang/ru/): `ОСНОВНАЯ.ДОПОЛНИТЕЛЬНАЯ.ИСПРАВЛЕНИЕ`
— исправления повышают последнюю цифру, новые возможности — среднюю, несовместимые изменения — первую.
Текущая версия видна в шапке панели и в выводе установщика.

## [1.7.3] — 2026-10-10

### Изменено
- Название папки, все видео которой в архиве на Яндекс Диске (на сервере их нет), зачёркнуто — в «Скачанных видео»
  и в списке папок поля «Подпапка».

## [1.7.2] — 2026-10-10

### Исправлено
- Блок «Задания» показывается только на вкладке «Видео», не в «Настройках».

## [1.7.1] — 2026-10-10

### Исправлено
- Если сервер на несколько секунд недоступен (например, перезапускается при обновлении), действие не обрывается
  ошибкой «запрос не прошёл»: панель предупреждает и повторяет запрос до 4 раз.
- Вкладки, открытые до версии 1.2 (до «Заданий»), сами перезагружаются в новую версию.

### Добавлено
- Полоса «Панель обновилась — обновить страницу», если на сервере уже более новая версия, чем в открытой вкладке.

## [1.7.0] — 2026-10-10

### Изменено
- Блоки в «⚙ Настройках» сворачиваются и разворачиваются щелчком по заголовку; по умолчанию свёрнуты,
  панель запоминает, какие раскрыты. Переходы по ссылкам (например, из предупреждения о месте) раскрывают нужный блок.

## [1.6.1] — 2026-10-10

### Исправлено
- Отзыв ссылки для просмотра: окно подтверждения открывалось под окном ссылок и не нажималось.
  Подтверждения и уведомления теперь всегда поверх других окон.

## [1.6.0] — 2026-10-10

### Добавлено
- **Страница просмотра по секретной ссылке**: значок «Поделиться» у папки → ссылка `…/s/<код>` на 1, 7, 30 дней
  или бессрочно. Открывается без пароля панели: плеер (следующее видео включается само), список видео,
  скачивание по одному и всей папкой в ZIP; не индексируется поисковиками. Видна только эта папка.
- Список активных ссылок папки со сроком и числом просмотров, отзыв любой ссылки одной кнопкой.
  Ссылки переживают переименование папки и удаляются вместе с папкой.

## [1.5.0] — 2026-10-10

### Добавлено
- **Зашифрованная резервная копия** (⚙ Настройки → «Резервная копия»): один файл `.tvpbak` с ключами Telegram API,
  входом в Telegram, подключением Яндекс Диска и всеми настройками. Шифрование AES-256-GCM, ключ из вашего пароля
  через scrypt. Видео и пароль панели не входят.
- **Восстановление из копии** — в настройках и сразу на экране первого запуска («Есть резервная копия?»):
  переезд на новый сервер без повторного входа в Telegram и подключения Диска.
- Зависимость `cryptography`.

## [1.4.0] — 2026-10-10

### Добавлено
- **Уведомление о новой версии**: раз в 6 часов панель анонимно проверяет релизы на GitHub; если есть версия новее,
  в шапке появляется «Доступна X.Y.Z». По нажатию — что нового во всех пропущенных версиях и команда обновления
  для вашего способа установки (Docker или установщик) с кнопкой «Скопировать». Панель сама себя не обновляет.
- ⚙ Настройки → «Обновления»: включить/выключить проверку, «Проверить сейчас».

## [1.3.1] — 2026-10-10

### Исправлено
- Настройки очистки: поля с числами стоят рядом со своими подписями.

## [1.3.0] — 2026-10-10

### Добавлено
- **Автоочистка сервера** (⚙ Настройки → «Очистка сервера», каждое правило включается отдельно):
  удалять видео старше N дней и/или самые старые, пока свободного места меньше X ГБ. Удаляются только видео,
  которые точно есть на Яндекс Диске (сверка имени и размера); папка остаётся «в архиве», видео
  восстанавливаются с Диска. Папки с идущими заданиями не трогаются. Проверка каждые 30 минут и после каждого
  задания, кнопка «Очистить сейчас», журнал очистки.
- **Предупреждение о месте**: полоса над вкладками и красная полоска диска, когда свободно меньше Y ГБ.
- `TZ` в `example.env` — часовой пояс для времени в журналах в Docker.

## [1.2.0] — 2026-10-10

### Добавлено
- **Домен и HTTPS для Docker Compose**: встроенный Caddy (профиль `https`) — включается строками
  `TVP_DOMAIN` и `COMPOSE_PROFILES=https` в `.env`, сертификат Let's Encrypt выпускается и продлевается сам,
  `http://` перенаправляется на `https://`; порты Caddy настраиваются (`TVP_HTTP_PORT`, `TVP_HTTPS_PORT`).
- README: раздел «Домен и HTTPS для Docker Compose» — встроенный Caddy, Caddy на сервере, nginx + certbot.
- README и `example.env`: обязательный пароль в `.env` для Docker Compose.

## [1.1.0] — 2026-10-09

### Добавлено
- Установка через **Docker Compose**: `Dockerfile`, `docker-compose.yml` (данные в `./data` и `./videos`,
  панель в контейнере работает не от root, ffmpeg внутри, проверка здоровья).
- **`example.env`** — образец настроек с пояснениями; `.env` создаётся из него (установщик делает это сам).
- Параметр `TVP_FORWARDED_ALLOW_IPS` — доверенные обратные прокси.

### Изменено
- **Всё хранится в `/opt/tg-video-panel`**: `.env` (пароль), `data/` (вход в Telegram, ключи, задания), `videos/`.
  Репозиторий можно клонировать прямо в эту папку.
- Установщик сам переносит данные со старого расположения (`/var/lib/tg-video-panel`, `/etc/tg-video-panel.env`):
  вход в Telegram, подключение Диска, задания и видео сохраняются.

## [1.0.0] — 2026-10-09

Первая публичная версия.

### Telegram
- Скачивание всех видео из групп и каналов аккаунта; вход в Telegram через панель (api_id/api_hash, код, облачный пароль).
- Период «с — по» с точным подсчётом видео (обычные группы, супергруппы, каналы, альбомы).
- Оригинальные имена файлов, как при ручном сохранении; повторы — `имя (1).mp4`; выбор расширения;
  сжатие до 1080/720/480p через ffmpeg.
- Пропуск уже скачанного, докачка; FloodWait и сетевые ошибки — ожидание и повтор.
- Папка по умолчанию «ГГГГ-ММ-ДД Название группы», выбор существующей папки в поле «Подпапка».

### Задания
- Очередь заданий, параллельные скачивания и загрузки (лимиты в настройках, меняются на лету).
- Задания работают в фоне на сервере и продолжаются после перезапуска службы.

### Яндекс Диск
- Подключение по коду (ya.ru/device), ожидание подтверждения на сервере.
- Загрузка каждого видео сразу после скачивания; обход ограничения скорости API; повторы при сбоях.
- Публичная ссылка на папку, отправка в чат (автоматически или с выбором чата), шаблон сообщения, `info.txt`.
- Архив: после проверки видео удаляются с сервера, папка восстанавливается с Диска.
- Список папок на Диске: ссылка, отправка, переименование, удаление в Корзину Диска.

### Панель
- Вход по паролю; файлы на сервере: просмотр, скачивание, ZIP папки, переименование, удаление.
- Вкладки «Видео» и «Настройки», тёмная/светлая тема, работа во встроенных браузерах и на телефоне.
- Установщик для Ubuntu 22.04/24.04: режимы по IP, с доменом (HTTPS через Caddy, без перезаписи чужого
  Caddyfile) и через SSH-туннель.
