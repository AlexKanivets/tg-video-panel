# Telegram Video Panel

Веб-панель для пакетного скачивания видео из Telegram-групп и каналов на свой сервер — с загрузкой на Яндекс Диск,
публичной ссылкой на папку и отправкой этой ссылки в любой чат.

Ставится на любой сервер с Ubuntu одной командой, работает в фоне: нажали «Начать» — можно закрыть вкладку.

## Возможности

- **Скачивание всех видео** из группы или канала, к которым у вашего аккаунта есть доступ.
- **Период**: «с даты — по дату» (пусто — с начала / по сегодня), подсчёт видео за период до начала.
- **Оригинальные имена файлов**, как при ручном сохранении в Telegram; совпадающие получают номер `имя (1).mp4`.
  Можно сменить расширение (`.mp4`, `.mov`, `.m4v`, `.mkv`) или сжать до 1080/720/480p (ffmpeg).
- **Уже скачанное пропускается** — можно докачивать, в том числе после сбоя или перезапуска сервера.
- **Очередь заданий и параллельность**: несколько скачиваний сразу, несколько видео одновременно, всё настраивается.
  Задания переживают перезапуск службы и продолжаются сами.
- **Яндекс Диск**: загрузка каждого видео сразу после скачивания, повтор при сбоях сети, публичная ссылка на папку,
  отправка ссылки в чат (автоматически или в выбранный вручную), файл `info.txt` с описанием в папке.
- **Архив**: после проверки, что все видео есть на Диске, они удаляются с сервера; папка остаётся в списке,
  её можно восстановить с Диска одной кнопкой.
- **Файлы на сервере**: смотреть в браузере, скачать по одному или всей папкой в ZIP, переименовать, удалить.
- **Уведомление о новой версии** с описанием изменений и командой обновления.
- **Зашифрованная резервная копия** настроек и входа — переезд на другой сервер за минуту.
- **Страница просмотра по секретной ссылке** со сроком действия — смотреть и скачивать видео без пароля панели.
- **Автоочистка сервера**: старше N дней и/или при нехватке места — только то, что уже есть на Диске;
  предупреждение, когда место заканчивается.
- Вход в панель по паролю, тёмная и светлая тема, работает с телефона.

## Требования

- Сервер с **Ubuntu 22.04 или 24.04** (подойдёт недорогой VPS: 1 ГБ RAM, место — под ваши видео).
- **Сервер должен быть за пределами России.** С российских серверов Telegram недоступен — панель не сможет войти
  в аккаунт (ошибка `TimeoutError` при подключении).
- Аккаунт Telegram и ключи API с [my.telegram.org](https://my.telegram.org) (бесплатно, см. ниже).
- Для Яндекс Диска — аккаунт Яндекса (по желанию).

## Установка на сервер

Два способа — выберите один: **установщик** (systemd, проще всего) или **Docker Compose**.
Всё хранится в одной папке `/opt/tg-video-panel`.

### Способ 1. Установщик

Подключитесь к серверу по SSH и выполните:

```bash
sudo apt-get update && sudo apt-get install -y git
sudo git clone https://github.com/AlexKanivets/tg-video-panel.git /opt/tg-video-panel
cd /opt/tg-video-panel
sudo bash install.sh --ip
```

В конце установщик покажет **адрес панели и пароль** — сохраните пароль.

### Режимы установки

| Команда | Адрес панели | Когда подходит |
|---|---|---|
| `sudo bash install.sh --ip` | `http://IP-сервера:8765` | Быстрый старт. Соединение **без шифрования** |
| `sudo bash install.sh video.example.com` | `https://video.example.com` | Рекомендуется. Нужен домен, A-запись которого указывает на сервер. HTTPS-сертификат выпускается автоматически (Caddy). Для Docker — см. [Домен и HTTPS для Docker Compose](#домен-и-https-для-docker-compose) |
| `sudo bash install.sh` | `http://127.0.0.1:8765` через SSH-туннель | Панель вообще не видна из интернета |

Для режима с доменом установщик ставит Caddy из репозитория Ubuntu. Если Caddy у вас уже настроен для других сайтов,
ваш `Caddyfile` не перезаписывается: делается копия, блок панели дописывается в конец, конфигурация проверяется.

Для режима без домена подключитесь туннелем и откройте `http://127.0.0.1:8765` у себя:

```bash
ssh -N -L 8765:127.0.0.1:8765 root@IP-сервера
```

### Способ 2. Docker Compose

Нужны Docker и плагин Compose ([установка Docker](https://docs.docker.com/engine/install/ubuntu/)).

```bash
sudo git clone https://github.com/AlexKanivets/tg-video-panel.git /opt/tg-video-panel
cd /opt/tg-video-panel
sudo cp example.env .env
sudo nano .env                      # ОБЯЗАТЕЛЬНО впишите пароль в строку TVP_PASSWORD=
sudo docker compose up -d --build
```

> ⚠️ **Обязательно задайте пароль в `.env`** — строка `TVP_PASSWORD=`. Это единственная защита панели:
> по паролю входят в панель, а через неё — в ваш Telegram и на Яндекс Диск.
>
> - Пароль должен быть длинным и случайным. Сгенерировать: `openssl rand -base64 18`
>   и вставить результат: `TVP_PASSWORD=результат_команды`.
> - Не оставляйте строку пустой: без пароля Compose не запустится и покажет ошибку
>   «Задайте TVP_PASSWORD в файле .env».
> - Не используйте простые пароли и пароли из примеров — панель открыта в интернет.
> - Сменить пароль: исправьте `.env` и выполните `sudo docker compose up -d`.
>
> При установке через `install.sh` (способ 1) пароль создаётся автоматически и показывается в конце установки.

Панель — `http://IP-сервера:8765`, вход по паролю из `.env`. Порт и адрес задаются там же: `TVP_PORT`, `TVP_BIND`
(`127.0.0.1` — если панель за вашим обратным прокси с HTTPS).

Данные лежат рядом, в `./data` (вход в Telegram, ключи, задания) и `./videos`. Внутри контейнера панель работает
не от root, ffmpeg уже установлен. Логи — `sudo docker compose logs -f`, остановка — `sudo docker compose down`.

> Не ставьте оба способа одновременно на одном сервере — они займут один порт.

### Домен и HTTPS для Docker Compose

Чтобы панель открывалась по `https://video.example.com`, сначала в DNS вашего домена создайте **A-запись**,
указывающую на IP сервера, и откройте в фаерволе порты **80 и 443**. Дальше — один из трёх вариантов.

**Вариант А. Встроенный Caddy** — проще всего, если на сервере порты 80/443 свободны (нет другого веб-сервера).
Допишите в `.env`:

```bash
TVP_DOMAIN=video.example.com
COMPOSE_PROFILES=https
TVP_BIND=127.0.0.1
TVP_FORWARDED_ALLOW_IPS=*
```

и выполните `sudo docker compose up -d`. Запустится второй контейнер — Caddy: он сам получит сертификат
Let's Encrypt, будет продлевать его и перенаправлять `http://` на `https://`. Сертификаты хранятся в томе Docker
и переживают перезапуски. Если сертификат не выпускается — смотрите `sudo docker compose logs caddy`
(чаще всего A-запись ещё не обновилась или закрыт порт 80).

**Вариант Б. Caddy уже установлен на сервере** (обслуживает другие сайты). В `.env` панели:
`TVP_BIND=127.0.0.1` и `TVP_FORWARDED_ALLOW_IPS=*`, затем `sudo docker compose up -d`.
Допишите в конец `/etc/caddy/Caddyfile`:

```
video.example.com {
    reverse_proxy 127.0.0.1:8765
}
```

и выполните `sudo systemctl reload caddy` — сертификат Caddy выпустит сам.

**Вариант В. nginx.** В `.env` панели — те же две строки, что в варианте Б. Создайте
`/etc/nginx/sites-available/tg-video-panel`:

```nginx
server {
    listen 80;
    server_name video.example.com;

    client_max_body_size 0;
    location / {
        proxy_pass http://127.0.0.1:8765;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_buffering off;          # ZIP-архивы и видео отдаются потоком
        proxy_read_timeout 3600s;     # большие ZIP скачиваются долго
    }
}
```

затем включите сайт и получите сертификат:

```bash
sudo ln -s /etc/nginx/sites-available/tg-video-panel /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
sudo apt-get install -y certbot python3-certbot-nginx
sudo certbot --nginx -d video.example.com
```

Во всех вариантах `TVP_BIND=127.0.0.1` закрывает прямой доступ `http://IP:8765` — панель открывается только
по HTTPS, и пароль с кодом Telegram больше не передаются открытым текстом. `TVP_FORWARDED_ALLOW_IPS=*`
нужен, чтобы панель видела, что открыта по HTTPS (в Docker прокси приходит не с адреса 127.0.0.1);
это безопасно, пока порт панели закрыт снаружи через `TVP_BIND=127.0.0.1`.

## Первый запуск

1. Откройте панель и войдите по паролю из вывода установщика.
2. **Ключи Telegram API**: зайдите на [my.telegram.org](https://my.telegram.org) → *API development tools* →
   создайте приложение (название любое) → скопируйте `api_id` и `api_hash` в панель.
3. **Вход в Telegram**: номер телефона → код придёт в приложение Telegram → (облачный пароль, если включён).
   Входить нужно один раз — сессия сохраняется на сервере.
4. Выберите группу, при желании период и подпапку, нажмите **«Начать скачивание»**.

## Яндекс Диск (по желанию)

1. Создайте своё приложение на [oauth.yandex.ru/client/new](https://oauth.yandex.ru/client/new):
   - платформа — **«Веб-сервисы»**, Redirect URI — `https://oauth.yandex.ru/verification_code`;
   - доступы **Яндекс Диск REST API**: «Доступ к информации о Диске», «Чтение всего Диска»,
     «Запись в любом месте на Диске».
2. В панели: **⚙ Настройки → Яндекс Диск** → вставьте ClientID и Client secret → «Подключить».
3. Откройте [ya.ru/device](https://ya.ru/device), введите показанный код и подтвердите доступ —
   панель подключится сама (вкладку можно не держать открытой).

Дальше в настройках можно включить:

- **автозагрузку** — каждое видео уходит на Диск сразу после скачивания;
- **архив** — после проверки видео удаляются с сервера (папка остаётся, восстанавливается с Диска);
- **info.txt** — файл с описанием папки и ссылкой;
- **отправку ссылки** — в группу, откуда видео, в «Избранное» или в выбранный чат; текст по шаблону
  с подстановками `{folder}`, `{period}`, `{count}`, `{size}`, `{link}`.

> Яндекс ограничивает скорость загрузки видео через API (~120 КБ/с). Панель обходит это: загружает файл
> с временным именем и сразу переименовывает — так скорость примерно в 10 раз выше.

## Очистка сервера и свободное место

**⚙ Настройки → Очистка сервера** — каждое правило включается отдельно:

- **удалять видео старше N дней**;
- **удалять самые старые видео, когда свободно меньше X ГБ** — пока свободного места снова не станет X;
- **предупреждать, когда свободно меньше Y ГБ** — над вкладками появится жёлтая полоса.

Удаляются только видео, которые **точно есть на Яндекс Диске** (сверяются имя и размер); без подключённого
Диска очистка ничего не удаляет. Папка остаётся в «Скачанных видео» с пометкой «в архиве», видео можно вернуть
кнопкой «Восстановить с Диска». Проверка идёт каждые 30 минут и после каждого задания; есть кнопка
«Очистить сейчас» и журнал — что и когда удалено.

## Настройки параллельности

**⚙ Настройки → Параллельность**: сколько заданий скачивания идёт одновременно (по умолчанию 2), сколько видео
одновременно качается из Telegram (3) и загружается на Диск (3). Больше — быстрее, но Telegram может попросить
подождать (панель подождёт сама) и сервер расходует больше канала и места.

## Ссылка для просмотра без пароля

У папки в «Скачанных видео» — значок **«Поделиться»**: выберите срок (1, 7, 30 дней или бессрочно) и получите
ссылку вида `https://ваш-адрес/s/код`. По ней открывается страница **без пароля панели**: плеер, список видео
(следующее включается само), скачивание по одному и всей папкой в ZIP. Видна только эта папка — ни панель,
ни другие папки, ни настройки. Код ссылки — 192 бита случайных данных, подобрать его нельзя.

В том же окне — все активные ссылки папки со сроком и числом просмотров; любую можно отозвать, и она сразу
перестанет открываться. После срока ссылка отключается сама.

## Резервная копия и переезд на другой сервер

**⚙ Настройки → Резервная копия → «Скачать копию»** — один зашифрованный файл `.tvpbak`: ключи Telegram API,
вход в Telegram, подключение Яндекс Диска и все настройки панели (видео и пароль панели не входят).
Файл шифруется вашим паролем (AES-256-GCM, ключ из пароля через scrypt).

На новом сервере установите панель, войдите по паролю панели и на экране «Ключи Telegram API» раскройте
**«Есть резервная копия? Восстановить»** — выберите файл, введите пароль копии. Панель сразу будет подключена
к Telegram и Яндекс Диску. Видео при необходимости вернутся с Диска кнопкой «Восстановить с Диска» у папок.

> ⚠ Запомните пароль копии — без него файл не открыть никак. Храните файл надёжно: в нём вход в ваш Telegram.

## Обновление

Панель сама сообщает о новой версии: в шапке появляется зелёная метка **«Доступна X.Y.Z»** — по нажатию видно,
что нового, и команду обновления для вашего способа установки. Проверка — раз в 6 часов анонимным запросом
к GitHub; отключается в ⚙ Настройки → «Обновления». Обновляется панель командой на сервере:

```bash
cd /opt/tg-video-panel
sudo git pull
sudo bash install.sh --ip              # установщик: тот же режим, что при установке
# или
sudo docker compose up -d --build      # Docker Compose
```

Пароль, вход в Telegram, подключение Диска, задания и видео сохраняются. Незавершённые задания после
перезапуска продолжатся сами.

> **Обновление с 1.0.0:** данные раньше хранились в `/var/lib/tg-video-panel` и `/etc/tg-video-panel.env`.
> Установщик 1.1.0 сам переносит их в `/opt/tg-video-panel` (видео не копируются, а перемещаются — это мгновенно).

## Версии

Текущая версия видна в шапке панели (`v1.0.0`) и в выводе установщика. Что изменилось в каждой версии —
в [CHANGELOG.md](CHANGELOG.md) и на странице [Releases](https://github.com/AlexKanivets/tg-video-panel/releases).

Поставить конкретную версию вместо последней:

```bash
cd ~/tg-video-panel
git fetch --tags
sudo git checkout v1.6.0
sudo bash install.sh --ip
```

Вернуться на последнюю: `git checkout main && git pull`, затем снова `install.sh`.

## Управление

```bash
sudo systemctl status tg-video-panel      # состояние
sudo systemctl restart tg-video-panel     # перезапуск
sudo journalctl -u tg-video-panel -f      # логи
```

Сменить пароль панели: `sudo nano /opt/tg-video-panel/.env` (строка `TVP_PASSWORD=`), затем
`sudo systemctl restart tg-video-panel` (или `sudo docker compose up -d` для Docker).

Все параметры с пояснениями — в [example.env](example.env).

## Где что хранится и безопасность

Всё — в `/opt/tg-video-panel`:

| Что | Где |
|---|---|
| Программа | `/opt/tg-video-panel` (`app.py`, `.venv`) |
| Пароль панели и параметры | `/opt/tg-video-panel/.env` (доступ только root) |
| Ключи Telegram API, токен Яндекс Диска, настройки | `/opt/tg-video-panel/data/config.json` |
| Вход в Telegram | `/opt/tg-video-panel/data/tg_session.session` |
| Очередь и история заданий | `/opt/tg-video-panel/data/jobs.json` |
| Видео | `/opt/tg-video-panel/videos/<папка>` |

- Панель работает от отдельного системного пользователя `tvp` без входа в систему; данные доступны только ему.
- **Никому не передавайте `.env`, `tg_session.session` и `config.json`** — это пароль панели и полный доступ
  к вашему аккаунту Telegram и к Яндекс Диску. В репозиторий они не попадают (см. `.gitignore`), образец
  настроек без секретов — `example.env`.
- По возможности ставьте панель с доменом (HTTPS): в режиме `--ip` пароль панели и код Telegram передаются
  без шифрования. Как подключить домен — для установщика см. «Режимы установки», для Docker —
  «Домен и HTTPS для Docker Compose».
- Ссылки на Яндекс Диск и ссылки для просмотра (`/s/…`) открывает любой, у кого они есть, — давайте их только
  тем, кому нужно, ставьте срок и отзывайте ненужные.

## Удаление

```bash
sudo systemctl disable --now tg-video-panel        # Docker: cd /opt/tg-video-panel && sudo docker compose down --rmi all
sudo rm -f /etc/systemd/system/tg-video-panel.service
sudo systemctl daemon-reload
sudo userdel tvp
sudo rm -rf /opt/tg-video-panel     # ВНИМАНИЕ: удалит и скачанные видео, и вход в Telegram
```

Если ставили с доменом — удалите блок `# tg-video-panel` из `/etc/caddy/Caddyfile` и выполните
`sudo systemctl reload caddy`.

## Запуск на своём компьютере (без сервера)

Нужен Python 3.9+ (и ffmpeg, если нужно сжатие). Панель откроется на `http://127.0.0.1:8765` без пароля,
видео сохраняются в любую папку.

- macOS: `bash start.command`
- Linux: `bash run.sh`
- Windows: `run.bat`

## Частые проблемы

- **«Нет связи с Telegram» / `TimeoutError`** — сервер в России или Telegram заблокирован провайдером.
  Нужен сервер в другой стране.
- **После ввода пароля пустая страница с шапкой** — проверьте адрес: возможно, открыта панель на другом сервере.
  Если вверху красная ошибка — в ней причина (часто мешает антивирус или блокировщик рекламы).
- **Кнопки «Удалить» не срабатывают во встроенном браузере** (Telegram, ярлык на iPhone) — обновите панель:
  подтверждения сделаны собственным окном и работают везде.
- **Счётчик видео за период и реальное количество** — совпадают; если нет, сообщите в Issues с типом чата
  (группа / супергруппа / канал).
- **`apt-get update` пишет ошибку про сторонний репозиторий** — установщик продолжит работу со старыми списками
  пакетов; почините или удалите сломанный репозиторий в `/etc/apt/sources.list.d/`.

## Как устроено

Один файл `app.py` (версия — константа `VERSION` в начале файла): [Starlette](https://www.starlette.io/) + [uvicorn](https://www.uvicorn.org/) +
[Telethon](https://github.com/LonamiWebs/Telethon) (вход как пользователь Telegram, MTProto) +
[httpx](https://www.python-httpx.org/) (REST API Яндекс Диска). Интерфейс встроен в `app.py`,
без сборки и внешних CDN. `install.sh` ставит всё в venv и создаёт службу systemd.
